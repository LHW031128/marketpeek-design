# MarketPeek

**iOS 시세 위젯 · 앱 디자인** — 장기투자자를 위한 시세 위젯

## 참고

- 화면에 나오는 시세 · 환율 · 자산 금액과 뉴스 문구는 모두 디자인용 예시 데이터예요. 실시간 시세가 아니에요.
- 종목 로고 자리는 실제 회사 로고 대신 이니셜로 표시했어요.
- 상승은 빨강, 하락은 파랑으로 표시했어요.
- 목표 환율 알림은 시연용 설정 화면이에요.
- 잠금화면 배너(라이브 액티비티형)는 이번 버전 기획에서 빠진 기능이라 참고용이에요.
